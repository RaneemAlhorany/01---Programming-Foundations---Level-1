# 01 - Programming Foundations - Level 1

My notes, activities, and progress through **Programming Foundations - Level 1** by **Abu Hadhoud**.

## 📚 About

This level introduces the fundamental concepts behind **computers, data, and programming**.

It focuses on understanding how computers represent, process, and work with data, as well as the basic concepts behind programming languages and program execution.

## 🧠 Topics Covered

* Data, Information, Knowledge, and Wisdom
* Computer Functions and Components
* Binary System
* Computer Speeds and Units
* Hexadecimal System
* Octal System
* Bytes and Terminology
* Computer Networks
* Programming Languages
* Compiler, Interpreter, Assembler, Linker, and Loader
* Computer Operations
* Calculation Priorities
* Variables and Constants

## 🎯 Goal

Build a strong foundation in computer and programming concepts before moving into deeper programming topics.

---

**Learn the foundations → Understand how computers work → Build from there**
